# My T Companion 1.10.36

## All-car notifications on each TeslaMate server

- Every enabled notification now covers every vehicle on the paired TeslaMate
  server, regardless of which vehicle is currently selected in My T.
- Obsolete selected-car filters from older App pairings are ignored and removed
  automatically when Companion starts.
- Existing notification choices remain unchanged. No database migration,
  re-pairing, Tesla login, or vehicle wake is required.

This is a compatibility hardening release for multi-vehicle TeslaMate servers.
