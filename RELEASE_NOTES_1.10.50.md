# My T Companion 1.10.50

## Highlights
- Friend Together settings in `.env` survive Companion upgrades (`update.sh` / `install.sh` no longer drop `FRIEND_TOGETHER_*`).
- If Friend Together was already enabled, HostBox and My T should stay「已启用」after the bump without a manual re-enable.

## Upgrade
Use HostBox or `./update.sh` on an installer-managed deployment.
